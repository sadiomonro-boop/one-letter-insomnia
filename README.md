One letter for a day that never really started: **I, for insomnia** — awake at 3 a.m., ceiling-staring, the whole day wrecked by a night that never ended. This program writes exactly that one letter to `/output/entry.txt` for make.fun's "One Letter for Your Day" bounty: one byte, no newline, nothing else.

## Run it

```sh
node main.ts
```
